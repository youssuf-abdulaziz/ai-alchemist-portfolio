# Font stack: Syne / DM Sans / JetBrains Mono

The typography uses three fonts loaded via `next/font/google`: Syne (display/hero headings, weight 700–800), DM Sans (body/UI, weight 400/500), and JetBrains Mono (monospace labels, section markers, skill tags). We replaced the starter Geist/Geist-Mono pair. This matches the design brief exactly and gives the editorial-plus-hacker duality the identity calls for, while `next/font` keeps the fonts self-hosted and performant.
